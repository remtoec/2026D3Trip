# 北海道・雪與湯 — 2026 D3 Trip

六人北海道冬季自駕旅行提案，以繁體中文（香港）呈現。

- 日期：2026 年 12 月 13 日集合，12 月 20 日結束；8 日 7 夜。
- 機場：新千歲 CTS 出入。
- 人數：6 位成人（5 男 1 女），7 人車自駕。
- 主題：雪景、溫泉、朋友旅行，以及合理住宿預算。
- 資料查核日期：2026-10-12。
- 狀態：行程提案，未預訂；房價為篩選預算，未確認指定日期空房。

計算及篩選只在瀏覽器本地執行；沒有追蹤程式、帳戶或後端。重新整理後會還原預設值。
