更新：2026-10-12。繁體中文（香港）北海道冬季自駕行程，按地區分頁及互動地圖比較住宿、雪場與景點。

## 旅行安排

- 2026/12/13 集合；13–17 日六人同行（5 男 1 女）。
- 夫婦 18 日返港，住宿五晚；四位男士 18–19 日滑雪，20 日返港，住宿七晚。
- 新千歲進出、七人車；想有雪、天然溫泉，住宿舒服但價格合理。
- 夫婦獨立房、四位男士各一床；航班及滑雪程度待確認。

## 新分頁

- **地圖與地區**：九個地區分頁，住宿／雪場景點篩選、搜尋、每頁三張卡（手機兩張）。卡片定位、標記選卡、詳情及官方／Google Maps 連結。
- **行程比較**：二世古安努普利、富良野滑雪、富良野＋Tomamu 三條完整替代線。另列旭川 Kamui、Pippu、札幌國際及 Sahoro 候選。
- **住宿與預算**：七晚全組價格可逐晚修改，按六人／四人分攤，夫婦五晚／四人七晚分開計。支援夫婦 17 日先住千歲的早機安排。
- **活動／準備**：期間活動、訂房交通及來源分頁。

預設打開富良野地區；三個方案擇一，並非全部串在同一次旅行。

## 價格及設施

住宿全部是**每晚全組篩選目標**，不是指定日期即時報價或空房確認；四人價不能直接由六人價推算。

2026–27 兩日纜車：安努普利單區 ¥14,000；富良野免費會員兩張日票 ¥15,000，Prince 官網住宿＋會員＋入住前一日17:00前加購可用 ¥13,000；Tomamu 12/1–20 住宿客早季兩日 ¥9,000。

La Vista、新富良野 Prince、Park Hills、Northern 等有天然溫泉；Tomamu 木林之湯、Sahoro 麥飯石浴及 JR Inn 大浴場不能當成天然溫泉。
Tomamu 冰之村 12/20 17:00 先開，預設返港行程不包括。

預算裝備／雪服預設 ¥20,000、課堂 ¥15,000 是可調預留額；接駁預設0為未加入。機票、租車、油費、高速費、額外餐飲與保險另計。匯率預設 ¥1 = HK$0.05。

## 地圖與開發

靜態網站，無建置步驟：`index.html`、`assets/style.css`、`assets/data.js`、`assets/app.js`。
GitHub Pages 使用 main 根目錄，推送後自動部署。

地圖使用固定版 Leaflet 1.9.4 CDN 及 OpenStreetMap tiles，保留地圖版權。沒有追蹤、帳戶或訂房功能；預算只在記憶體，重新整理還原。

區域／民宿地址不明者有「約略位置」標示，Google Maps及官方連結用來確認地址。La Vista 標記取自酒店官方嵌入地圖中心；民宿標記為公開鄰近車站或區域位置。虛線只表示次序，並非道路導航。

CDN 地圖未能載入時仍可使用分頁、住宿卡及 Google Maps；底圖錯誤亦有提示。
