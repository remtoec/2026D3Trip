## 活動安排

以札幌、美瑛、富良野、Moving Inn／十勝、千歲分隊點、二世古六個基地比較。單程一至兩小時候選不代表順路，連來回和遊覽通常佔半日；活動並非全部加入行程。

已核對的限制包括：

- Moving Inn冬季河畔桑拿官網參考¥10,000／人、約1小時；16日是否營運及有場次需問宿主，不假設已包在房價。
- 廣尾Santa Land亮燈涵蓋12月中，官方列16:00–22:00；如安排，與住宿晚餐／桑拿時間協調。
- 六花亭帶廣本店喫茶室逢星期三休息，16/12不排堂食；店舖外帶按開門時間。
- 晩成溫泉10–3月逢星期二休息，16/12為星期三。
- 美瑛青池今季12月16:30亮燈；冬季並非夏天藍色水面。
- 聖誕樹之木官方現行規定樹前禁停、步行觀看及建議接駁，標成先確認，不當直接自駕停車點。
- 旭山動物園冬季10:30–15:30；企鵝散步需積雪足夠，不保證12月中已開始。
- 四季彩之丘雪上項目需確認開季，不以冬季宣傳頁保證14–15日已開。
- 珠寶冰通常1月中至2月下旬、冰上釣公魚通常12月下旬後，不列作16日保證活動。
